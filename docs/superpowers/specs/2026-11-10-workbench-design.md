# 化合物数据与可解释筛选系统 V1.0

用户已确认采用研究工作台方向；本设计将该方向落实为本地可运行软件及真实操作截图手册。

## 目标与范围
将三个现有数据文件建立可复建索引，提供总览、多源检索与分页、结构详情、Morgan 指纹相似度、可解释性质筛选、候选对比、质量审计、筛选记录保存与导出。保留原始数据及历史脚本。DrugBank 没有结构字段，不虚构结构关联；BBB 和 activity 只称来源标签，不称预测。

## 方案
采用 Python 标准库 HTTP 服务、SQLite、RDKit、原生 HTML/CSS/JavaScript。相比重型 SPA + API 方案，本地部署和离线复现更直接；相比仅包装原脚本，能够串联数据检索、计算、解释和记录。使用现有 drug_info Python 环境验证，提供依赖和启动说明。仅监听回环地址。

## 界面
左侧固定导航，右侧宽屏工作区；中文功能名称；蓝绿主色，清晰统计卡片、表格、分子图和可解释证据。页面展示数据实值、来源和算法信息。空结果、无结构、计算失败和无效输入必须明确显示。

## 证据与交付
通过浏览器实际操作所有功能，保存完整页面 PNG 与操作清单；生成含封面、运行环境、数据说明、全部功能操作和截图、技术特点、源代码统计口径的 PDF。名称版本暂定，申请人等未知内容不编造。不承诺法定新颖性或审批结果。源代码按交付时实际文件统计，数据和第三方库不计入。

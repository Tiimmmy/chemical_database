一、软件概述与功能范围

本软件面向化合物数据整理与早期研究筛选，读取项目现有化合物、血脑屏障标签及 DrugBank 资料，将数据查询、分子结构计算、相似结构探索、可解释筛选和研究证据归档串联为一个本地工作流程。

功能模块主要操作与输出
数据总览统计三个数据来源、可解析结构、唯一结构并提供研究入口。
多源检索与详情按来源、关键词和标签查询、分页、CSV 导出；展示来源行号、结构、计算性质与原始字段。
相似结构探索输入或带入 SMILES，设置阈值，以 Morgan 指纹和 Tanimoto 系数计算相似结构。
可解释筛选同时应用五项性质上限，列出命中依据，导出完整命中结果。
候选分子对比最多三个候选并列展示结构和性质，支持移除与清空。
质量与溯源展示非法、缺失、源内重复统计及来源文件 SHA256。
筛选记录保存参数、命中标识、数据指纹及库版本，查看历史和导出 JSON。

软件不包含训练模型、活性预测或自动实验决策。activity 与 BBB 为原始来源标签。原有采集和片段脚本继续保留，但不属于本次工作台界面功能。

二、运行环境与启动操作

项目本次实现与验证环境
操作系统Linux，本项目目录 /home/mytu/Project/personal/chemical_database
解释器Python 3.12；建议独立虚拟环境
化学计算RDKit 2026.09.1
其他依赖openpyxl 读取 XLSX；SQLite 随 Python 提供；Playwright 用于截图和 PDF
浏览器Google Chrome；页面无需远程脚本、字体或在线接口
  1. 确认三个源数据文件保持原目录结构，安装 requirements.txt 列出的依赖。
  2. 在项目根目录执行 ./run.sh。可通过 CHEMDB_PYTHON 指定解释器。
  3. 首次运行生成 runtime/chemical.sqlite 索引，终端显示服务地址后再打开页面。
  4. 浏览器访问 http://127.0.0.1:8765。仅监听本地回环地址，无登录步骤。
  5. 关闭页面不影响服务；在运行终端按 Ctrl+C 停止。重新启动后筛选历史继续保留。

端口占用时可执行 ./run.sh --port 8766，并访问相应地址。源数据变更时再次启动会重建对应索引；历史记录中的旧文件指纹仍保留。

三、数据口径与连续操作路线

数据文件记录数非法结构缺失结构源内重复
Dataset/BBB_10648.csv10,648201
compound_info.csv2,424000
DrugBankAll.xlsx14,313000

记录数按来源行统计，保留重复来源；唯一结构按 RDKit 规范化 SMILES 统计。DrugBank 不含 SMILES，未将其所有条目计入缺失结构。非法结构不参与计算筛选。MW 单位为 g/mol，TPSA 为 Å²，LogP 无量纲，HBD/HBA 分别为氢键供体/受体计数。

推荐连续流程：启动软件 → 核对总览 → 检索 tmy0 → 阅读结构与来源 → 将其带入相似探索 → 设置五项性质条件 → 执行并导出筛选 → 加入候选对比 → 保存筛选记录 → 核对来源指纹 → 下载证据 JSON。

DrugBank 使用独立资料阅读路径：选择该来源 → 按 ID 或原文关键词查询 → 查看药理资料字段。不存在结构时，结构计算与对比功能不对该记录启用。

五、技术特点及实现对应关系

技术特点实际实现及边界
多源字段保留与结构关联独立保存来源、行号、原始字段和规范化 SMILES。仅结构完全相同时提供关联，不根据名称或描述猜测对应关系。
透明的相似结构探索Morgan 半径 2、2048 位指纹；Tanimoto 系数；保留来源行，按相似度降序，最多返回前 60 条。
可解释多条件筛选统一计算 MW、LogP、HBD、HBA、TPSA，以包含边界的 AND 逻辑筛选；逐项展示数值与阈值。
筛选证据归档服务端重新核验条件与命中 ID，保存全部 ID、前 100 条结果快照、来源文件 SHA256 和 RDKit 版本；支持 JSON 复核。
计算值与原值并存主表使用统一计算口径，详情保留原始性质字段，便于追踪口径差异。
本地可复建索引SQLite 持久化；启动时校验来源文件内容指纹，未变更来源复用索引。

八、运行维护与常见问题

情况处理步骤
服务未启动或页面打不开检查终端启动信息、解释器依赖和端口；必须在允许本地套接字的环境运行。受限沙箱报 Operation not permitted 时，改在正常终端运行。
无查询结果检查数据来源与标签是否一致，清空关键词后重新查询。DrugBank 按原文英文关键词匹配。
SMILES 解析失败检查结构字符串；可从已知记录详情直接带入。不得将普通名称当作 SMILES 输入。
筛选结果不符合预期核对五个上限均需满足；检查来源选择及数值单位。更改条件后必须再次执行筛选，保存的是已执行结果。
候选数量达到上限到候选对比移除现有条目，再加入其他分子。候选列表在当前浏览器 localStorage 中保存。
备份与迁移停止服务后备份原始文件、源代码及 runtime/chemical.sqlite；浏览器候选列表与数据库筛选历史分别保存。历史归档也可单独导出 JSON。
重新制作材料运行 generate_materials.sh，检查截图清单与 PDF；每次采集会新增一条示例筛选历史，不删除已有研究记录。
